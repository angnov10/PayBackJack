# PayBackJack Entwicklungsprotokoll (Antigravity)

Dieses Dokument definiert die Regeln für die Zusammenarbeit an diesem Projekt.

## 1. Fehlervermeidung & Verifizierung
- **Dokumentations-Abgleich:** Jede Verwendung von `ea.edu`-Klassen MUSS gegen die lokale HTML-Dokumentation in `Engine Alpha Dokumentation/` geprüft werden.
- **Dubletten-Check:** Vor dem Anlegen neuer Felder oder Methoden muss die gesamte Klasse nach existierenden Logiken durchsucht werden.
- **Typ-Sicherheit:** Methoden-Signaturen müssen exakt mit der API übereinstimmen.

## 2. GitHub Synchronisation
- Nach jedem erfolgreichen Feature-Update oder Bugfix erfolgt ein automatischer Sync.
- Commit-Messages müssen aussagekräftig sein.

## 3. Design & Layout
- **Skalierung:** Alle Assets und Layouts basieren auf dem Faktor 6 für Positionen (320x180 -> 1920x1080) und Faktor 3 für Asset-Namen (Card-Pixel).
- **Sidebar:** Die Sidebar hat einen festen X-Offset von 120 Pixeln zum linken Rand.

## 4. Langzeitgedächtnis
- Wichtige Entscheidungen werden als "Knowledge Items" gespeichert.
